Introdu tokenul GitHub care are drept de scriere doar pe acest repo. Se păstrează doar pe acest dispozitiv.

Setări avansate

Cum obțin un token?
  1. Deschide GitHub → Fine-grained tokens.
  2. La Repository access alege Only select repositories și selectează acest repo.
  3. La Permissions → Contents alege Read and write.
  4. Generează tokenul și lipește-l aici.
